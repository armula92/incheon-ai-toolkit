# 공공디자인 AI 툴킷 for 인천

인천 시민 디자인 워크숍을 위한 공공디자인 협력 툴킷입니다. 키오스크에서 메뉴를 고르듯 다섯 단계를 차례로 고르면, 마지막에 하나의 사업 기획안이 만들어집니다.

- 사이트: https://www.armula.com/incheon-ai-toolkit/
- 인천 창의디자인 팔레트 소개: https://www.armula.com/incheon-ai-toolkit/palette/ (`palette/index.html`, 사진과 글꼴을 담은 단일 파일)
- 단계: 어디에(Where) → 누구를(Who) → 무엇을(What) → 어떻게(How) → 사업 기획안(2026.11.26 어디에를 먼저)
- 기타 직접 입력: 단계마다 목록에 없는 대상, 장소, 과제, 전략을 「기타」 칸에 적을 수 있고, 적은 내용은 기획안에 그대로 들어갑니다.
- AI 도우미: 단계마다 함께 생각할 대상, 공간, 전략을 추천하고, 기획안에서는 앞의 선택으로 공간 구성 요소를 제안합니다(2026.11.24 무엇으로 단계 삭제). 이 판의 추천은 시연용 규칙 기반 추천입니다. 기획안 화면에서는 생성형 AI에 그대로 붙여 넣을 이미지 프롬프트와 기획안 프롬프트를 제공합니다.
- 기획안은 PDF로 저장하거나, 주소를 복사해 다른 사람과 나눌 수 있습니다.

## 근거 자료

- 인천광역시 공공디자인 진흥계획 재정비 1차 중간보고(2026.10.15): 6개 주제, 30개 이슈, 인천 창의디자인 팔레트 30개 사업
- 인천시 공공디자인 진흥계획 시민디자인단 워크숍 계획안(2026.10.29)
- 충청남도 공공디자인 진흥계획 「충남 공공팔레트 90」, 광진구 협력디자인 툴킷(안)

## 사진

Wikimedia Commons의 자유 이용 사진(CC0, 퍼블릭 도메인, CC BY, CC BY-SA)을 썼고, 저작자와 라이선스는 사이트의 「참고 자료」에 모두 밝혔습니다. 장면 예시 이미지 3장은 제작 리소스의 생성 이미지입니다.

## 구조

빌드 없이 정적 파일로 돌아갑니다. `index.html`, `assets/`(CSS, JS, 글꼴, 사진), `data/`(선택지 `toolkit.js`, 인천 팔레트 `palette.js`, 사진 출처 `credits.js`).
